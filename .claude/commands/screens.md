Пересними скриншоты для описания процесса.

1. Убедись, что база запущена: `npm run db:up`.
2. Удали старые снимки и сними заново: `rm -rf docs/screenshots && mkdir -p docs/screenshots && PW_CHANNEL=chrome npm run screens`. Конфиг сам сбросит демо и соберёт прод-сборку.
3. Открой 4–5 ключевых снимков (`orlov_today`, `orlov_rating_whatif_70`, `metodist_queue_1280`, `login_360`, `desktop_orlov_today`) и проверь: карточка пересдачи на «Сегодня» видна, нет переносов строк в шапке, нет горизонтальной прокрутки.
4. Если что-то не так — исправь вёрстку, а не снимок. Потом закоммить `docs/screenshots` отдельным коммитом.
