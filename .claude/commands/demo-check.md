Проверь, что демо готово к показу.

1. `npm run typecheck && npm run lint && npm test` — всё зелёное.
2. `PW_CHANNEL=chrome npm run test:e2e` — все e2e на 360 px зелёные (тест `99-seed-dates` в конце сам вернёт свежее демо).
3. `npm run db:reset` — демо в исходном состоянии; даты от сегодняшнего дня.
4. `curl -s localhost:3100/api/health` при запущенном сервере → `{"ok":true,"db":"up"}`.
5. Сверь с `pitch/demo-script.md`: у `orlov` на «Сегодня» есть «Заявку вернули» и «Пересдача 2 через 12 дней», у `metodist` в очереди есть новые заявки.
6. Отчитайся списком: что проверено, что упало, что исправлено.
