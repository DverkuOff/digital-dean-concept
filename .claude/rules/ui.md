# Интерфейс

- Mobile-first: проверять на 360 px. Никаких фиксированных ширин больше 320 px, длинные строки переносятся.
- Компоненты — shadcn/ui из `src/components/ui`, иконки — lucide-react. Цвета только из токенов темы (`primary`, `warning`, `success`, `destructive`, `info`, `muted`).
- Изменения и переносы — `warning`, долги и отмены — `destructive`, готово — `success`.
- У каждого списка есть пустое состояние (`EmptyState`) с понятным текстом «что делать дальше».
- Формы: ошибки у поля (`aria-invalid`, `aria-describedby`), кнопка отправки с состоянием загрузки (`SubmitButton`).
- Иконкам без текста — `aria-label` у кнопки, декоративным — `aria-hidden`.
- Тексты по-русски, без канцелярита: «Заявку вернули: исправьте дату», а не «Заявка подлежит доработке».
- Название заявки — только `requestName()` из каталога, одно на всех экранах; статусы — только `STATUS_META`.
- Даты в формах — «дд.мм.гггг» (не `type=date`: его формат зависит от языка браузера).
- Время показывать через `src/lib/dates.ts` (Москва).
