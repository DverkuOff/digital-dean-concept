# Данные и миграции

- Схема — `src/server/db/schema.ts`. После изменения: `npm run db:generate`, затем `npm run db:reset`. Миграции не править руками.
- Сид только вымышленный: имена из списков в `scripts/seed.ts`, без реальных людей и логотипов.
- Все даты в сиде — от `now` (`addDays`, `mskAt`), без захардкоженных дат: демо должно работать и 28.11.
- Демо-аккаунты и их «сюжет» описаны в docs/specs/data-model.md; меняешь сид — обнови таблицу и контрольный пример в docs/specs/rating.md.
