# Безопасность: правила для серверного кода

- Данные студента читаются только в `src/server/dal/*`. Первая строка функции DAL — `await requireStudent()` (или `requireStaff()`).
- Владелец — в условии запроса: `where(and(eq(t.id, id), eq(t.studentId, me.id)))`. Нельзя сначала выбрать по id, а потом сравнить владельца в JS.
- Чужое и несуществующее неотличимы: `return null` → `notFound()` → 404.
- id из URL и форм проверять `isUuid()` до запроса.
- В каждом `"use server"` файле каждая экспортируемая функция начинается с `studentForAction()` / `staffForAction()` и обрабатывает `null`.
- Никогда не принимать `studentId`, `role`, `status` студента из формы. Статус меняет только методист по `STAFF_TRANSITIONS`.
- Агрегаты по другим студентам — только числа, без имён и id.
- Новая проверка доступа → новый сценарий в `e2e/01-security.spec.ts`.
