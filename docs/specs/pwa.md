# Спека: PWA и офлайн-доступ

Статус: реализовано 17.11.2026. Код: `public/sw.js`, `src/app/manifest.ts`, `src/components/app/pwa.tsx`, `src/components/app/sign-out-button.tsx`. Тест: `e2e/06-pwa.spec.ts`.

## Зачем
Официальное «МГИМО.Расписание» ругают за «бесконечную загрузку» (docs/research/02-competitors.md). Расписание нужно в метро и в подвальной аудитории, где сети нет. Кабинет ставится на главный экран как приложение и открывает самое нужное без сети.

## Что работает без сети
«Сегодня», «Расписание» (день и неделя), «Учёба». Сверху плашка «Нет сети · данные на 15:40, обновлено 12 минут назад». Если сеть есть, но сервер не ответил и страница взята из кэша, плашка говорит «Не удалось обновить» и даёт кнопку обновления.
Не кэшируются: заявки, уведомления, профиль, рейтинг, очередь методиста, API и любые POST. Без сети на них открывается `offline.html` без персональных данных.

## Как устроено
| Что | Стратегия |
|---|---|
| `/_next/static/*` (скрипты, стили, шрифты с хешем в имени) | cache-first |
| Три персональные страницы | network-first; удачный ответ сохраняется в `orientir-pages-<ключ>` |
| Прогрев | после входа страница сообщает воркеру ключ пользователя, воркер скачивает три страницы и их скрипты (не чаще раза в 5 минут) |
| Остальные переходы | только сеть; без сети — `offline.html` |
| RSC-запросы, prefetch, `/api/*` | не трогаем |

## Безопасность кэша
Персональные страницы лежат в Cache Storage браузера на устройстве студента. Поэтому:
1. **Отдельный кэш на пользователя.** Ключ — первые 16 символов `sha256("orientir-cache:" + id студента)`. Он не секрет и не id. Когда приходит другой ключ, кэши всех прочих ключей удаляются: следующий человек на том же устройстве не увидит чужие страницы.
2. **Выход стирает кэш.** Кнопка «Выйти» сначала удаляет `orientir-pages-*` и метаданные, потом завершает сессию на сервере.
3. **Истёкшая сессия стирает кэш.** Если сервер перенаправил на `/login`, воркер удаляет все персональные кэши.
4. Воркер не кэширует ответы с редиректом и ошибкой, а также POST, то есть Server Actions.
5. Сервер по-прежнему проверяет сессию на каждом запросе. Кэш — это копия уже показанных студенту его же страниц, а не обход доступа.

## Тест (`e2e/06-pwa.spec.ts`)
- Манифест, иконки и `sw.js` отдаются без входа.
- Орлов входит, воркер сообщает «прогрето». Без сети: `/grades` показывает «Есть долг» и плашку «Нет сети», `/schedule` открывается, а `/requests` даёт офлайн-заглушку.
- После «Выйти» в Cache Storage нет `orientir-pages-*`. Без сети `/grades` показывает заглушку без слова «Макроэкономика».
- Проверка теста на поломку: если отключить очистку при выходе, тест падает.

## Установка
Android/Chrome: меню → «Установить приложение». iPhone: «Поделиться» → «На экран „Домой“». Иконки — свой знак-компас (`public/icons/`, отрисованы из SVG логотипа).
